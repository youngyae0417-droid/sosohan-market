# 신청 접수는 네이버폼에 남겨둔다

셀러 참가 신청은 계속 네이버폼으로 받는다. 이 도구는 **선정 이후**만 담당하며, 확정 셀러 명단을 네이버폼 엑셀 업로드 또는 이름·전화번호 붙여넣기로 받아들인다.

신청 접수까지 직접 만드는 편이 자동 연동 측면에서는 깔끔하지만, 네이버폼은 외부 API 연동이 사실상 막혀 있어 어느 쪽이든 자동 연동은 불가능하다. 그러면 남는 차이는 "신청 폼을 다시 만드는 부담"과 "신청 창구가 바뀌어 셀러가 혼란을 겪는 위험"뿐이고, 둘 다 얻는 것 없이 지불하는 비용이다.

## Consequences

- 확정 셀러 명단 반입은 항상 담당자의 수동 조작(업로드 또는 붙여넣기)에서 시작한다. 자동화할 여지가 없으므로 이 지점을 자동화하려는 시도는 하지 않는다.
- 신청 셀러 단계의 데이터는 이 도구가 보관하지 않는다. 도구가 아는 셀러는 확정 셀러뿐이다.
- 나중에 신청 접수까지 흡수하기로 마음이 바뀌면 이 결정을 뒤집게 되며, 그때는 셀러에게 신청 창구 변경을 안내해야 한다.
