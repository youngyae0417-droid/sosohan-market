# 공지를 문자 전문에서 "문자 + 링크"로 나눈다

기존에는 공지글 전문을 개별 문자에 그대로 담아 보냈다. 앞으로는 핵심 정보(날짜, 시간, 장소, 입금)만 문자 본문에 남기고, 지도와 주차 안내, 배치도, 상세 유의사항은 플리마켓 공개 페이지에 두고 문자에는 링크만 넣는다.

이유는 비용이 아니다. 셀러 20명 규모에서 문자 전문(LMS)과 짧은 문자(SMS)의 차이는 행사당 1,500원 남짓이라 의미가 없다. 진짜 이유는 **플리마켓마다 장소와 날짜가 바뀌고, 확정된 일정이 뒤집히는 변경 공지가 실제로 존재한다**는 것이다. 문자에 전문을 담으면 정보가 바뀔 때마다 전원에게 다시 보내야 하고, 셀러의 문자함에는 서로 어긋나는 안내가 여러 개 쌓인다. 링크가 고정되어 있으면 페이지만 고쳐도 셀러가 여는 순간 항상 최신이 보인다.

## Consequences

- 플리마켓당 공개 페이지는 1개뿐이며 링크는 끝까지 바뀌지 않는다. 공지 5종이 그 한 페이지에 누적된다.
- 배치도도 이 원칙을 따라 페이지에 올리고 문자로는 링크만 보낸다. 사진을 MMS로 붙이면 화질이 깎여 부스 번호가 안 보이고, 배치가 바뀌면 다시 보내야 한다.
- 공개 페이지에는 셀러 개인정보를 일절 표시하지 않는다. 링크를 아는 사람은 누구나 열 수 있기 때문이다.
