# 소소한시장 운영 도구 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 소소한시장 담당자가 확정 셀러 명단을 반입해 공지 5종을 작성하고, 셀러별로 문자를 보내고 실패를 추적하며, 플리마켓마다 고정 링크의 공개 페이지를 운영하는 도구를 만든다.

**Architecture:** 순수 도메인 로직(전화번호 정규화, 명단 파싱, 템플릿 렌더링)을 `src/domain/`에 네트워크·DB 의존 없이 두고 vitest로 TDD한다. 그 위에 Supabase(Postgres + Storage)를 다루는 `src/server/` 어댑터를 얹고, Next.js App Router가 관리자 화면과 공개 페이지를 그린다. 문자 발송은 셀러 1명당 1콜로 순차 처리해 셀러별 성공·실패를 정확히 기록한다.

**Tech Stack:** Next.js 15 (App Router, TypeScript) · Supabase (Postgres, Storage) · solapi 6 · exceljs 4.4 · vitest · Vercel

**Spec:** [SPEC.md](../../../SPEC.md) — 용어는 [CONTEXT.md](../../../CONTEXT.md), 결정 근거는 [docs/adr](../../adr)

## Global Constraints

- Node.js 20 이상 (`solapi` v6이 18 이상을 요구)
- `solapi`는 **서버 전용**. API 키가 클라이언트 번들에 절대 들어가면 안 된다. `solapi` import는 `src/server/` 아래에서만 허용한다.
- 전화번호는 저장·발송 전에 항상 `01012345678` 형태로 정규화한다. 특수문자가 남으면 발송이 실패한다.
- 공개 페이지에는 어떤 경우에도 셀러 이름·전화번호를 렌더링하지 않는다.
- 사용자에게 보이는 문구는 전부 한국어. CONTEXT.md의 용어를 그대로 쓴다. **"팀", "참가자", "어드민", "마켓", "행사"는 금지어**이며 각각 "셀러", "확정 셀러", "담당자", "플리마켓"을 쓴다.
- 코드 식별자는 영어(`Seller`, `Market`, `Entry`, `Notice`, `Dispatch`)를 쓰되, 공지 종류 값은 도메인 용어 그대로 한국어 문자열(`'선정'`, `'사전안내'`, `'리마인드'`, `'변경'`, `'배치도'`)을 쓴다.
- 저장소가 **공개**다. 키는 `.env.local`에만 두고 커밋하지 않는다. `.gitignore`가 이미 `.env*`를 막고 있다.
- 참가비는 플리마켓 단위다. 셀러별 금액 필드를 만들지 않는다.
- 개인화 변수는 `{이름}`과 `{링크}` 두 개뿐이다. 세 번째 변수를 추가하지 않는다.

```ts
export type PhoneErrorReason = '빈값' | '숫자없음' | '휴대폰번호아님' | '자릿수오류';

export type PhoneResult =
  | { ok: true; phone: string }
  | { ok: false; reason: PhoneErrorReason };

/**
 * 전화번호를 `01012345678` 형태로 정규화한다.
 * 솔라피는 특수문자가 섞인 번호를 거부하므로 발송·저장 전에 반드시 통과시켜야 한다.
 */
export function normalizePhone(raw: string): PhoneResult {
  const trimmed = (raw ?? '').trim();
  if (trimmed === '') return { ok: false, reason: '빈값' };

  const digits = trimmed.replace(/\D/g, '');
  if (digits === '') return { ok: false, reason: '숫자없음' };

  let local = digits;

  // 국가번호: +82 10..., 8210... → 010...
  if (local.startsWith('82')) local = '0' + local.slice(2);

  // 엑셀이 전화번호를 숫자로 해석하면 앞자리 0이 사라진다: 1012345678 → 01012345678
  if (local.length === 10 && local.startsWith('10')) local = '0' + local;

  if (!local.startsWith('010')) return { ok: false, reason: '휴대폰번호아님' };
  if (local.length !== 11) return { ok: false, reason: '자릿수오류' };

  return { ok: true, phone: local };
}

export function formatPhone(phone: string): string {
  return `${phone.slice(0, 3)}-${phone.slice(3, 7)}-${phone.slice(7)}`;
}
```

```ts
import { normalizePhone, formatPhone } from './phone';
import type { SellerInput } from './types';

export type RosterIssue = { line: number; raw: string; reason: string };
export type RosterResult = { rows: SellerInput[]; issues: RosterIssue[] };

/** 머리글로 흔히 쓰이는 값. 이 단어만 있는 줄은 데이터가 아니다. */
const HEADER_WORDS = ['이름', '성명', '셀러명', '연락처', '전화번호', '휴대폰', '번호'];

function isHeaderRow(cells: string[]): boolean {
  const filled = cells.filter(c => c !== '');
  return filled.length > 0 && filled.every(c => HEADER_WORDS.includes(c));
}

function splitLine(line: string): string[] {
  // 탭이 있으면 탭 기준(엑셀 복사), 없으면 쉼표 기준으로 나눈다.
  const parts = line.includes('\t') ? line.split('\t') : line.split(',');
  return parts.map(p => p.trim());
}

function collect(rowsRaw: { cells: string[]; line: number; raw: string }[]): RosterResult {
  const rows: SellerInput[] = [];
  const issues: RosterIssue[] = [];
  const seen = new Map<string, number>();

  for (const { cells, line, raw } of rowsRaw) {
    const filled = cells.filter(c => c !== '');
    if (filled.length === 0) continue;
    if (isHeaderRow(cells)) continue;

    // 번호로 파싱되는 칸을 찾는다. 덕분에 열 순서를 몰라도 된다.
    let phone: string | null = null;
    let phoneIndex = -1;
    for (let i = 0; i < filled.length; i++) {
      const parsed = normalizePhone(filled[i]);
      if (parsed.ok) {
        phone = parsed.phone;
        phoneIndex = i;
        break;
      }
    }

    if (phone === null) {
      issues.push({ line, raw, reason: '전화번호를 찾을 수 없음' });
      continue;
    }

    const name = filled.filter((_, i) => i !== phoneIndex).join(' ').trim();
    if (name === '') {
      issues.push({ line, raw, reason: '이름을 찾을 수 없음' });
      continue;
    }

    if (seen.has(phone)) {
      issues.push({ line, raw, reason: `이미 있는 전화번호 (${formatPhone(phone)})` });
      continue;
    }

    seen.set(phone, line);
    rows.push({ name, phone });
  }

  return { rows, issues };
}

export function parsePastedRoster(text: string): RosterResult {
  const lines = (text ?? '').split(/\r?\n/);
  return collect(
    lines.map((raw, i) => ({ cells: splitLine(raw), line: i + 1, raw })),
  );
}

export function parseRosterCells(cells: string[][]): RosterResult {
  return collect(
    cells.map((row, i) => {
      const asStrings = row.map(c => (c === null || c === undefined ? '' : String(c).trim()));
      return { cells: asStrings, line: i + 1, raw: asStrings.join('\t') };
    }),
  );
}
```

```ts
import ExcelJS from 'exceljs';
import { parseRosterCells, type RosterResult } from './roster';

/**
 * exceljs의 셀 값은 문자열·숫자만이 아니라 리치텍스트, 수식 결과,
 * 하이퍼링크 객체일 수도 있다. 전부 문자열로 눌러 담는다.
 */
function cellText(value: unknown): string {
  if (value === null || value === undefined) return '';
  if (value instanceof Date) return value.toISOString();
  if (typeof value === 'object') {
    const v = value as {
      text?: unknown;
      result?: unknown;
      richText?: { text: string }[];
    };
    if (Array.isArray(v.richText)) return v.richText.map(r => r.text).join('');
    if (v.text !== undefined) return String(v.text);
    if (v.result !== undefined) return String(v.result);
    return '';
  }
  return String(value);
}

/**
 * 네이버폼에서 내려받은 엑셀을 읽는다. 첫 시트만 본다.
 * 전화번호가 숫자 셀로 저장되어 앞자리 0이 사라진 경우는 normalizePhone이 복원한다.
 */
export async function parseXlsxRoster(buffer: ArrayBuffer): Promise<RosterResult> {
  const workbook = new ExcelJS.Workbook();
  await workbook.xlsx.load(buffer);

  const sheet = workbook.worksheets[0];
  if (!sheet) return { rows: [], issues: [] };

  const cells: string[][] = [];
  sheet.eachRow({ includeEmpty: false }, row => {
    // row.values는 1-기반 배열이라 0번 자리가 비어 있다.
    const values = Array.isArray(row.values) ? row.values.slice(1) : [];
    cells.push(values.map(v => cellText(v).trim()));
  });

  return parseRosterCells(cells);
}
```

## Task 4B: 네이버폼 다열 엑셀에서 이름·연락처 열만 골라내기

**이 태스크는 최종 브랜치 리뷰가 찾아낸 실제 결함을 고친다. Task 8을 만들기 전에 반드시 해야 한다.**

Task 3의 파싱 규칙은 "전화번호로 파싱되는 칸을 찾고 **나머지를 모두 이름으로** 합친다"다. 이 규칙은 담당자가 이름·연락처 두 열만 복사해 붙여넣는 경로에서는 옳지만, **실제 네이버폼 엑셀 다운로드에서는 무너진다.** 실제 파일은 이런 모양이다:

| 제출시각 | 이름 | 연락처 | 판매 품목 | SNS 계정 |
|---|---|---|---|---|
| 2026-08-15 14:32 | 김하늘 | 010-1111-2222 | 수공예 액세서리 | @kimhaneul |

이때 전화번호는 올바르게 찾지만 이름이 `2026-08-15T05:32:01.000Z 김하늘 수공예 액세서리 @kimhaneul`이 된다. 그 문자열이 셀러 이름으로 저장되고 `{이름}님, …` 문자로 실제 발송된다. 게다가 `제출시각`·`판매 품목`이 `HEADER_WORDS`에 없어서 머리글 행이 걸러지지 않고 `1번째 줄: 전화번호를 찾을 수 없음` 오류까지 붙는다.

## Task 5: 공지 템플릿과 문자 타입 판정

개인화 변수는 `{이름}`과 `{링크}` **두 개뿐**이다(SPEC "공지"). 참가비·날짜·장소는 플리마켓 단위라 담당자가 문구를 쓸 때 직접 박는다.

```ts
/**
 * 공지 5종 기본 문구.
 * 개인화 변수는 {이름}과 {링크} 두 개뿐이다. 참가비·날짜·장소는 플리마켓 단위라

export const DEFAULT_TEMPLATES: Record<NoticeKind, string> = {
  선정:
    '{이름}님, 소소한시장 셀러로 확정되셨습니다.\n' +
    '참가비와 입금 계좌, 기한은 아래 링크에서 확인해 주세요.\n{링크}',
  사전안내:
    '{이름}님, 소소한시장 안내드립니다.\n' +
    '셋업 시간과 장소, 주차 안내는 아래 링크를 확인해 주세요.\n{링크}',

    '{이름}님, 소소한시장이 곧 열립니다.\n날짜와 셋업 시간을 다시 확인해 주세요.\n{링크}',
  변경:
    '{이름}님, 소소한시장 안내가 변경되었습니다.\n' +
    '바뀐 내용을 아래 링크에서 반드시 확인해 주세요.\n{링크}',
  배치도:
    '{이름}님, 소소한시장 배치도가 나왔습니다.\n' +
    '자리를 아래 링크에서 확인해 주세요.\n{링크}',
};

export function renderTemplate(
  body: string,
  vars: { 이름: string; 링크: string },
): string {
  return body
    .replaceAll('{이름}', vars.이름)
    .replaceAll('{링크}', vars.링크);
}

/**
 * 솔라피의 SMS/LMS 판정 기준인 EUC-KR 바이트 수를 센다.
 * 한글 등 ASCII 밖 문자는 2바이트, 나머지는 1바이트로 계산한다.
 */
export function smsByteLength(text: string): number {
  let bytes = 0;
  for (const ch of text) {
    bytes += (ch.codePointAt(0) ?? 0) > 0x7f ? 2 : 1;
  }
  return bytes;
}

/** 90바이트 이하면 SMS, 초과하면 LMS로 자동 발송된다. */
export function messageType(text: string): 'SMS' | 'LMS' {
  return smsByteLength(text) <= 90 ? 'SMS' : 'LMS';
}
```

```ts
import { createHmac, timingSafeEqual, randomBytes } from 'node:crypto';
import { cookies } from 'next/headers';
import { redirect } from 'next/navigation';

export const SESSION_COOKIE = 'sosohan_session';

function sign(payload: string, secret: string): string {
  return createHmac('sha256', secret).update(payload).digest('hex');
}

/** 랜덤 payload에 HMAC 서명을 붙인 토큰을 만든다. */
export function signSession(secret: string): string {
  const payload = randomBytes(16).toString('hex');
  return `${payload}.${sign(payload, secret)}`;
}

export function verifySession(token: string, secret: string): boolean {
  const [payload, mac] = (token ?? '').split('.');
  if (!payload || !mac) return false;

  const expected = sign(payload, secret);
  const a = Buffer.from(mac, 'utf8');
  const b = Buffer.from(expected, 'utf8');
  if (a.length !== b.length) return false;
  return timingSafeEqual(a, b);
}

function secret(): string {
  const value = process.env.SESSION_SECRET;
  if (!value) throw new Error('SESSION_SECRET이 필요합니다.');
  return value;
}

export async function isLoggedIn(): Promise<boolean> {
  const jar = await cookies();
  const token = jar.get(SESSION_COOKIE)?.value ?? '';
  return verifySession(token, secret());
}

/** 서버 컴포넌트 맨 위에서 호출한다. 미로그인이면 /login으로 보낸다. */
export async function requireLogin(): Promise<void> {
  if (!(await isLoggedIn())) redirect('/login');
}
```

```ts
import { cookies } from 'next/headers';
import { redirect } from 'next/navigation';
import { SESSION_COOKIE, signSession } from '@/server/auth';

export async function login(formData: FormData): Promise<void> {
  const input = String(formData.get('password') ?? '');
  const expected = process.env.ADMIN_PASSWORD;
  const sessionSecret = process.env.SESSION_SECRET;

  if (!expected || !sessionSecret) {
    throw new Error('ADMIN_PASSWORD와 SESSION_SECRET이 필요합니다.');
  }
  if (input !== expected) {
    redirect('/login?error=1');

  const jar = await cookies();
  jar.set(SESSION_COOKIE, signSession(sessionSecret), {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    path: '/',
    maxAge: 60 * 60 * 24 * 14, // 2주
  });

}
```

> - **1단계** — 붙여넣기/업로드 → 서버 액션이 파싱만 하고 `RosterResult`를 돌려준다. DB에 쓰지 않는다.

```ts
import { randomBytes } from 'node:crypto';
import { getDb } from '../db';

export type MarketRow = {
  id: string;
  slug: string;
  title: string;
  held_on: string;
  place: string;
  place_detail: string | null;
  setup_at: string | null;
  open_at: string | null;
  close_at: string | null;
  fee: number | null;
  bank_account: string | null;
  fee_due_on: string | null;
  notes: string | null;
  layout_path: string | null;
};

export type MarketInput = Omit<MarketRow, 'id' | 'slug' | 'layout_path'>;

/** 공개 페이지 주소. 추측하기 어렵게 만들되 링크는 끝까지 바뀌지 않는다. */
function newSlug(): string {
  return randomBytes(6).toString('base64url');
}

export async function createMarket(input: MarketInput) {
  const db = getDb();
  const slug = newSlug();
  const { data, error } = await db
    .from('market')
    .insert({ ...input, slug })
    .select('id, slug')
    .single();
  if (error) throw new Error(`플리마켓 저장 실패: ${error.message}`);
  return data as { id: string; slug: string };
}

export async function listMarkets(): Promise<MarketRow[]> {
  const db = getDb();
  const { data, error } = await db.from('market').select('*').order('held_on', { ascending: false });
  if (error) throw new Error(`플리마켓 조회 실패: ${error.message}`);
  return (data ?? []) as MarketRow[];
}

export async function getMarket(id: string): Promise<MarketRow | null> {
  const db = getDb();
  const { data, error } = await db.from('market').select('*').eq('id', id).maybeSingle();
  if (error) throw new Error(`플리마켓 조회 실패: ${error.message}`);
  return (data ?? null) as MarketRow | null;
}

export async function getMarketBySlug(slug: string): Promise<MarketRow | null> {
  const db = getDb();
  const { data, error } = await db.from('market').select('*').eq('slug', slug).maybeSingle();
  if (error) throw new Error(`플리마켓 조회 실패: ${error.message}`);
  return (data ?? null) as MarketRow | null;
}
```

```ts
import { getDb } from '../db';
import type { SellerInput } from '@/domain/types';

export type EntryRow = {
  entryId: string;
  sellerId: string;
  name: string;
  phone: string;
  paidAt: string | null;
};

/**
 * 전화번호가 유일 키다. 이미 있는 번호면 이름만 갱신하고 같은 셀러로 취급한다.
 * last_entry_on을 오늘로 올려 1년 보관 계산의 기준을 갱신한다.
 */
export async function upsertSellersAndEntries(marketId: string, rows: SellerInput[]) {
  const db = getDb();
  if (rows.length === 0) return { added: 0, already: 0 };

  const today = new Date().toISOString().slice(0, 10);
  const { data: sellers, error: sellerError } = await db
    .from('seller')
    .upsert(
      rows.map(r => ({ phone: r.phone, name: r.name, last_entry_on: today })),
      { onConflict: 'phone' },
    )
    .select('id, phone');
  if (sellerError) throw new Error(`셀러 저장 실패: ${sellerError.message}`);

  const { data: inserted, error: entryError } = await db
    .from('entry')
    .upsert(
      (sellers ?? []).map(s => ({ market_id: marketId, seller_id: s.id })),
      { onConflict: 'market_id,seller_id', ignoreDuplicates: true },
    )
    .select('id');
  if (entryError) throw new Error(`확정 셀러 저장 실패: ${entryError.message}`);

  const added = (inserted ?? []).length;
  return { added, already: rows.length - added };
}

export async function listEntries(marketId: string): Promise<EntryRow[]> {
  const db = getDb();
  const { data, error } = await db
    .from('entry')
    .select('id, paid_at, seller:seller_id (id, name, phone)')
    .eq('market_id', marketId);
  if (error) throw new Error(`확정 셀러 조회 실패: ${error.message}`);

  type Raw = { id: string; paid_at: string | null; seller: { id: string; name: string; phone: string } };
  return ((data ?? []) as unknown as Raw[])
    .map(r => ({
      entryId: r.id,
      sellerId: r.seller.id,
      name: r.seller.name,
      phone: r.seller.phone,
      paidAt: r.paid_at,
    }))
    .sort((a, b) => a.name.localeCompare(b.name, 'ko'));
}

export async function setPaid(entryId: string, paid: boolean) {
  const db = getDb();
  const { error } = await db
    .from('entry')
    .update({ paid_at: paid ? new Date().toISOString() : null })
    .eq('id', entryId);
  if (error) throw new Error(`입금 상태 저장 실패: ${error.message}`);
}
```

```ts
'use server';

import { revalidatePath } from 'next/cache';
import { redirect } from 'next/navigation';

import { upsertSellersAndEntries, setPaid } from '@/server/repo/seller';

function textOrNull(v: FormDataEntryValue | null): string | null {
  const s = String(v ?? '').trim();
  return s === '' ? null : s;
}

export async function createMarketAction(formData: FormData): Promise<void> {
  await requireLogin();

  const { id } = await createMarket({
    title: String(formData.get('title') ?? '').trim(),
    held_on: String(formData.get('held_on') ?? ''),
    place: String(formData.get('place') ?? '').trim(),
    place_detail: textOrNull(formData.get('place_detail')),
    setup_at: textOrNull(formData.get('setup_at')),
    open_at: textOrNull(formData.get('open_at')),
    close_at: textOrNull(formData.get('close_at')),
    fee: textOrNull(formData.get('fee')) === null ? null : Number(formData.get('fee')),
    bank_account: textOrNull(formData.get('bank_account')),
    fee_due_on: textOrNull(formData.get('fee_due_on')),
    notes: textOrNull(formData.get('notes')),
  });

  redirect(`/markets/${id}`);
}

/** 붙여넣기와 엑셀 업로드를 한 액션에서 받는다. 둘 중 채워진 쪽을 쓴다. */
export async function importRosterAction(formData: FormData): Promise<void> {
  await requireLogin();

  const marketId = String(formData.get('marketId') ?? '');
  const pasted = String(formData.get('pasted') ?? '').trim();
  const file = formData.get('file');

  let result;
  if (file instanceof File && file.size > 0) {
    // exceljs는 워크북 전체를 압축 해제해 메모리에 올린다. 크기 제한이 없으면
    // 거대한 파일이나 zip bomb 하나로 서버리스 함수가 메모리 초과로 죽는다.
    // 셀러 50명 명단은 수 KB이므로 2MB도 충분히 넉넉하다.
    const MAX_UPLOAD_BYTES = 2 * 1024 * 1024;
    if (file.size > MAX_UPLOAD_BYTES) {
      return {
        rows: [],
        issues: [
          {
            line: 0,
            raw: file.name,
            reason: '파일이 너무 큽니다(2MB 초과). 네이버폼에서 내려받은 응답 파일이 맞는지 확인해 주세요.',
          },
        ],
      };
    }

    // parseXlsxRoster는 async다 (exceljs의 읽기가 비동기).
    // 손상되었거나 엑셀이 아닌 파일이면 exceljs가 reject한다. 감싸지 않으면
    // 잘못된 파일 하나가 500 에러가 되므로, 실패를 기존 issues 통로로 흘려보내
    // 담당자가 다른 행 오류와 같은 자리에서 보게 한다.
    try {
      result = await parseXlsxRoster(await file.arrayBuffer());
    } catch {
      result = {
        rows: [],
        issues: [
          {
            line: 0,
            raw: file.name,
            reason: '엑셀 파일을 읽을 수 없습니다. 네이버폼에서 내려받은 파일이 맞는지 확인해 주세요.',
          },
        ],
      };
    }
  } else {
    result = parsePastedRoster(pasted);
  }

  await upsertSellersAndEntries(marketId, result.rows);
  revalidatePath(`/markets/${marketId}`);

  const issueParam = encodeURIComponent(JSON.stringify(result.issues.slice(0, 20)));
  redirect(`/markets/${marketId}?added=${result.rows.length}&issues=${issueParam}`);
}

export async function setPaidAction(formData: FormData): Promise<void> {
  await requireLogin();
  const entryId = String(formData.get('entryId') ?? '');
  const marketId = String(formData.get('marketId') ?? '');
  await setPaid(entryId, formData.get('paid') === 'on');
  revalidatePath(`/markets/${marketId}`);
}
```

```ts
import { SolapiMessageService } from 'solapi';

export type OutgoingMessage = { entryId: string; phone: string; text: string };
export type SendOutcome = {
  entryId: string;
  status: '성공' | '실패';
  messageId?: string;
  error?: string;
};

export type SendFn = (phone: string, text: string) => Promise<{ messageId?: string }>;

/**
 * 셀러 1명당 1콜로 순차 발송한다.
 * 대량 발송 API는 그룹 단위 응답이라 누가 실패했는지 특정할 수 없다.
 * 20~50명 규모에서는 순차 발송이 몇 초면 끝나고, 셀러별 실패를 정확히 남길 수 있다.
 * 한 명이 실패해도 멈추지 않는다.
 */
export async function sendOneByOne(
  messages: OutgoingMessage[],
  send: SendFn,
): Promise<SendOutcome[]> {
  const outcomes: SendOutcome[] = [];

  for (const m of messages) {
    try {
      const res = await send(m.phone, m.text);
      outcomes.push({ entryId: m.entryId, status: '성공', messageId: res.messageId });
    } catch (e) {
      outcomes.push({
        entryId: m.entryId,
        status: '실패',
        error: e instanceof Error ? e.message : String(e),
      });
    }
  }

  return outcomes;
}

/** 실제 솔라피 발송 함수. 서버에서만 호출된다. */
export function solapiSender(): SendFn {
  const key = process.env.SOLAPI_API_KEY;
  const secretKey = process.env.SOLAPI_API_SECRET;
  const from = process.env.SOLAPI_SENDER;
  if (!key || !secretKey || !from) {
    throw new Error('SOLAPI_API_KEY, SOLAPI_API_SECRET, SOLAPI_SENDER가 필요합니다.');
  }

  const service = new SolapiMessageService(key, secretKey);

  return async (phone, text) => {
    const res = (await service.send({ to: phone, from, text })) as unknown as {
      groupId?: string;
    };
    return { messageId: res?.groupId };
  };
}
```

```ts
import { getDb } from '../db';
import type { NoticeKind } from '@/domain/types';
import type { SendOutcome } from '../sms';

export type NoticeRow = {
  id: string;
  kind: NoticeKind;
  sms_body: string;
  page_body: string | null;
};

export async function listNotices(marketId: string): Promise<NoticeRow[]> {
  const db = getDb();
  const { data, error } = await db
    .from('notice')
    .select('id, kind, sms_body, page_body')
    .eq('market_id', marketId);
  if (error) throw new Error(`공지 조회 실패: ${error.message}`);
  return (data ?? []) as NoticeRow[];
}

export async function upsertNotice(
  marketId: string,
  kind: NoticeKind,
  smsBody: string,
  pageBody: string | null,
): Promise<string> {
  const db = getDb();
  const { data, error } = await db
    .from('notice')
    .upsert(
      {
        market_id: marketId,
        kind,
        sms_body: smsBody,
        page_body: pageBody,
        updated_at: new Date().toISOString(),
      },
      { onConflict: 'market_id,kind' },
    )
    .select('id')
    .single();
  if (error) throw new Error(`공지 저장 실패: ${error.message}`);
  return (data as { id: string }).id;
}

export async function recordDispatches(
  noticeId: string,
  sentBy: string,
  outcomes: SendOutcome[],
) {
  const db = getDb();
  if (outcomes.length === 0) return;
  const { error } = await db.from('dispatch').insert(
    outcomes.map(o => ({
      notice_id: noticeId,
      entry_id: o.entryId,
      sent_by: sentBy,
      status: o.status,
      message_id: o.messageId ?? null,
      error: o.error ?? null,
    })),
  );
  if (error) throw new Error(`발송 기록 저장 실패: ${error.message}`);
}

/** 공지별로 각 확정 셀러의 가장 최근 발송 상태. 재발송 대상을 고르는 근거다. */
export async function lastDispatchByEntry(
  noticeId: string,
): Promise<Map<string, { status: '성공' | '실패'; error: string | null; sent_by: string }>> {
  const db = getDb();
  const { data, error } = await db
    .from('dispatch')
    .select('entry_id, status, error, sent_by, created_at')
    .eq('notice_id', noticeId)
    .order('created_at', { ascending: true });
  if (error) throw new Error(`발송 기록 조회 실패: ${error.message}`);

  const map = new Map<string, { status: '성공' | '실패'; error: string | null; sent_by: string }>();
  for (const row of (data ?? []) as {
    entry_id: string; status: '성공' | '실패'; error: string | null; sent_by: string;
  }[]) {
    map.set(row.entry_id, { status: row.status, error: row.error, sent_by: row.sent_by });
  }
  return map;
}
```

```ts
/**
 * 대상: 'all'(확정 셀러 전원) | 'unpaid'(미입금 셀러만) | 'failed'(지난 발송 실패자만)
 * 문자는 취소가 불가능하므로 발송자 이름(sent_by)을 반드시 함께 남긴다.
 */
export async function sendNoticeAction(formData: FormData): Promise<void> {
  await requireLogin();

  const marketId = String(formData.get('marketId') ?? '');
  const kind = String(formData.get('kind') ?? '') as NoticeKind;
  const smsBody = String(formData.get('sms_body') ?? '');
  const pageBody = String(formData.get('page_body') ?? '') || null;
  const target = String(formData.get('target') ?? 'all');
  const sentBy = String(formData.get('sent_by') ?? '').trim();

  if (sentBy === '') throw new Error('발송자 이름을 골라 주세요.');

  const market = await getMarket(marketId);
  if (!market) throw new Error('플리마켓을 찾을 수 없습니다.');

  // 발송 직전에 문구를 저장한다. 보낸 문구와 저장된 문구가 어긋나면 안 된다.
  const noticeId = await upsertNotice(marketId, kind, smsBody, pageBody);

  const entries = await listEntries(marketId);
  let targets = entries;
  if (target === 'unpaid') {
    targets = entries.filter(e => e.paidAt === null);
  } else if (target === 'failed') {
    const last = await lastDispatchByEntry(noticeId);
    targets = entries.filter(e => last.get(e.entryId)?.status === '실패');
  }

  const link = `${process.env.NEXT_PUBLIC_SITE_URL ?? ''}/m/${market.slug}`;
  const messages: OutgoingMessage[] = targets.map(e => ({
    entryId: e.entryId,
    phone: e.phone,
    text: renderTemplate(smsBody, { 이름: e.name, 링크: link }),
  }));

  const outcomes = await sendOneByOne(messages, solapiSender());
  await recordDispatches(noticeId, sentBy, outcomes);

  revalidatePath(`/markets/${marketId}/notices`);
  revalidatePath(`/m/${market.slug}`);
}
```

- [ ] **Step 1: 구현 추가**

`src/server/repo/seller.ts`의 맨 위에 `import { normalizePhone } from '@/domain/phone';`를 더하고, 파일 끝에 다음을 추가한다:
```ts
/**
 * 셀러의 전화번호와 이름을 고친다.
 * 새 번호가 이미 다른 셀러로 있으면 그 셀러로 합친다:
 * 이 셀러의 확정 이력을 기존 셀러 쪽으로 옮기고 이 셀러 행을 지운다.
 */
export async function updateSellerPhone(
  sellerId: string,
  rawPhone: string,
  name: string,
): Promise<{ merged: boolean }> {
  const parsed = normalizePhone(rawPhone);
  if (!parsed.ok) throw new Error(`전화번호가 올바르지 않습니다: ${parsed.reason}`);

  const db = getDb();
  const { data: existing, error: findError } = await db
    .from('seller')
    .select('id')
    .eq('phone', parsed.phone)
    .maybeSingle();
  if (findError) throw new Error(`셀러 조회 실패: ${findError.message}`);

  const other = existing as { id: string } | null;

  if (other && other.id !== sellerId) {
    // 합치기: 확정 이력을 기존 셀러로 옮긴다.
    // unique(market_id, seller_id) 때문에 겹치는 플리마켓은 옮길 수 없으므로 먼저 지운다.
    const { data: mine } = await db.from('entry').select('id, market_id').eq('seller_id', sellerId);
    const { data: theirs } = await db.from('entry').select('market_id').eq('seller_id', other.id);
    const theirMarkets = new Set(((theirs ?? []) as { market_id: string }[]).map(t => t.market_id));

    for (const e of (mine ?? []) as { id: string; market_id: string }[]) {
      if (theirMarkets.has(e.market_id)) {
        await db.from('entry').delete().eq('id', e.id);
      } else {
        await db.from('entry').update({ seller_id: other.id }).eq('id', e.id);
      }
    }

    await db.from('seller').update({ name }).eq('id', other.id);
    const { error: delError } = await db.from('seller').delete().eq('id', sellerId);
    if (delError) throw new Error(`셀러 합치기 실패: ${delError.message}`);
    return { merged: true };
  }

  const { error } = await db
    .from('seller')
    .update({ phone: parsed.phone, name })
    .eq('id', sellerId);
  if (error) throw new Error(`셀러 저장 실패: ${error.message}`);
  return { merged: false };
}
```
